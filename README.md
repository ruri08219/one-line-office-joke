[One-Line Office Joke: 24-Hour Sprint](https://make.fun/c/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162)
competition on [make.fun](https://make.fun/).

## The joke

> My calendar blocked 'focus time' so my manager booked over it with a meeting called 'Quick Sync About Focus Time.'

## How it works

`main.py` (standard library only) writes the joke to `/output/entry.txt`
as UTF-8, then re-reads the file and asserts the bytes round-trip exactly.

```sh
python3 main.py
```
